Rezepte live auf allen Handys im Haushalt
1. Haushalts-Sync-Code (Empfohlen) Echtzeit

Gib denselben Code auf allen Smartphones in deinem Haushalt ein. Jede Änderung, jedes neue Rezept und die Einkaufsliste synchronisieren sich blitzschnell auf allen Geräten:

Aktueller Code: standard
2. Lokaler WLAN-Server (Ohne Cloud)

Du möchtest deine Rezepte 100% lokal auf deinem eigenen PC oder Raspberry Pi im WLAN speichern? Aktiviere diesen Modus und trage die Server-Adresse ein:

# Mini-Server: python -m pip install flask flask-cors
# Speichere dies als server.py und starte mit: python server.py
from flask import Flask, request, jsonify
from flask_cors import CORS
import json, os

app = Flask(__name__)
CORS(app)
DB = "recipes_db.json"

@app.route('/sync', methods=['GET', 'POST'])
def sync():
  if request.method == 'POST':
    with open(DB, 'w') as f: json.dump(request.json, f)
    return {"status":"ok"}
  if os.path.exists(DB):
    with open(DB) as f: return jsonify(json.load(f))
  return {}

app.run(host='0.0.0.0', port=8000)
Offline-Garantie: Auch wenn du unterwegs oder das WLAN kurz getrennt ist, bleibt alles im Browser gespeichert und synchronisiert sich automatisch neu.
